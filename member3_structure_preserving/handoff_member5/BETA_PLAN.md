## 主实验设计

固定 alpha0=0.5，beta预先设为 `{0,0.3,0.5,0.7,1}`。
每组使用同1349张Photo训练图、同10张外部画作及冻结配对、同模型权重、同M参数、
同512短边、同JPEG质量95。beta=0为普通AdaIN控制；beta=0.7保留为预先指定主设置。
训练集均为1349张原图+1349张增强图。不能让更多优化步数替代增强方法成为实验变量。

成员3负责图像与清单，成员4负责分类器。若已有完全相同的普通AdaIN训练，
beta=0可复用，不必重复计算。完整5组×3 seeds需15次分类训练；已有AdaIN可复用其中3次。
允许先用seed0做探索，但正式声明的主比较用seeds `{0,1,2}` 并清楚标记探索结果。
分类器采用共享ResNet-18、batch64、660步和final checkpoint；不按目标域分数选checkpoint。

生成入口：

```powershell
# 已运行的小规模流程检查
python -m member3_structure_preserving.generate sweep --limit 7 --alphas 0.5 --betas 0 0.3 0.5 0.7 1

# 后续完整消融：不加 limit
python -m member3_structure_preserving.generate sweep --alphas 0.5 --betas 0 0.3 0.5 0.7 1
```

完整扫描目录为 `data/aug_sp/sweeps/sweep_full/a0p5_b.../`，每组有独立manifest与生成记录。
普通AdaIN匹配参考图也会保存，不覆盖正式 `data/aug_sp/images/`。
成员4用清单的**绝对路径**启动多seed训练，并给各beta独立tag，避免已有结果被跳过。

## 指标和分析

1. **EdgeScore（越高越重叠）**：原图/生成图先转灰度再缩放到224×224；
   Canny阈值固定100/200。`2|Ec∩Es|/(|Ec|+|Es|)` 与现有P/R的F1等价。
   任一边缘集为空时结果未定义，报告有效数与缺失数，不偷偷记成0或1。
2. **LPIPS（越低越相似）**：RGB缩放224×224，归一化到[-1,1]，使用相同AlexNet版本的LPIPS。
   这是待补指标，当前结果中为null；不能填入估计值。更低不等于更好增强，可能只是风格变化变弱。
3. **配对比较**：按同一原图和风格，计算各beta相对beta=0的逐图差值；
   报告均值、图片间标准差、有效n，并按类别检查稳定性。
4. **分类结果（成员4）**：Art/Cartoon/Sketch分别报告和三域不加权平均；Photo单列。
   多seed标准差与逐图结构指标标准差必须分开。结构指标和分类提升的关联只能作分析，不能当因果证明。
5. **失败案例**：薄结构（如琴颈）、纹理背景产生的假保护、风格强度过弱或解码损伤。
   用相同content/style对照，M和alpha均固定[0,1]显示尺度，不按图单独拉伸。

## 需要控制的混杂

beta越大，平均alpha也越低。更高EdgeScore可能来自整体风格化变弱。
建议额外生成每张图 `alpha_uniform = mean(feature_alpha)` 的均匀强度AdaIN，
与空间图用相同内容/风格特征和解码器比较。这个控制尚未由批量CLI直接输出，
写在计划里，不写成已完成结果。后续alpha扫描可取 `{0.25,0.5,0.75,1}`，
与主beta消融分开分析，不混用两个变化因素解释收益。
