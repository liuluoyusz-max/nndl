# 结构保持风格增强：方法与实验约定

## 实现

内容图来自 Photo Training，风格图及配对来自成员4的冻结池。
AdaIN 使用成员2的原版 normalized VGG 编码器和解码器，不再训练新的生成模型。

1. 用与 AdaIN 完全相同的预处理，将内容图短边缩放到512，保持纵横比。
2. 转灰度，Gaussian 平滑（sigma=1），计算 Sobel 水平/垂直响应及梯度幅值。
3. 用每张图片梯度幅值的95%分位数归一化，再截断到 `[0,1]`。
   对极稀疏边缘，若分位数为零则用最大幅值；常量图返回零图。
4. 用3×3最大池化拓宽边缘，再 Gaussian 平滑（sigma=2），得到软结构图 `M`。
5. 构造 `alpha_map = alpha0 * (1 - beta * M)`，用面积平均缩小到 `relu4_1` 特征分辨率。
6. 在特征层混合 `F = alpha_map * AdaIN(Fc, Fs) + (1 - alpha_map) * Fc`，然后解码。

结构响应越强，保留的内容特征越多。保护发生在特征混合阶段。
结构图不是前景分割：背景轮廓、纹理也可能被保护。
解码器仍会改变图像，因此边缘保留是待验证的目标，不是保证。

## 参数与对照

- `alpha0=0.5`：与成员4正式实验协议一致。
- `beta=0.7`：初始工程默认值，**尚未通过实验选优**。
- `beta=0`：空间 alpha 退化为常数；应与同尺寸、同权重、同内容/风格的普通 AdaIN 完全一致。
- `alpha0=0`：输出为编码器/解码器重建，不等同于直接复制原图。
- 所有 beta 都复用相同内容/风格特征，图像缩放、保存格式和质量一致。
- 若输入长边不能被8整除，输出可能向上补齐到8的倍数；沿用成员2的网络尺寸行为，
  两组一致。不额外拉伸或裁剪其中一组。

建议预先设定 beta 网格 `{0, 0.3, 0.5, 0.7, 1}`，alpha 网格 `{0.25, 0.5, 0.75, 1}`。
扫描脚本只生成和汇总，不自动根据目标域测试结果选参数。
若必须选定单一参数，使用预先约定的规则或 Photo Validation；目标域只用于最终评价。

局部保护也降低了平均风格强度。即使 EdgeScore 改善，也不能单独证明空间位置是收益来源。
更严格的后续消融应加入平均 alpha 匹配的均匀风格化对照，并结合分类准确率判断，
不能只选择最像原图、风格变化最小的生成结果。

## 输出和可复现性

- 正式交付目录：`DATA_ROOT/aug_sp/`；图片在 `images/photo/<class>/...jpg`。
- `aug_sp/photo_train.txt` 为相对 `aug_sp/images/` 的两列清单，标签1～7。
- `aug_sp/manifest_ours.txt` 为成员4需要的6列清单；同样的内容另写到
  `DATA_ROOT/augmented/manifest_ours.txt`，直接引用 `aug_sp/images/` 的图片。
- `aug_sp/pairs.txt` 记录生成图、原图、风格及标签。
- 部分生成只写入 `previews/`；参数扫描写入 `sweeps/`，不覆盖正式清单。
- `generation.json` 记录代码/权重/内容文件哈希、冻结池哈希、参数及生成文件哈希。
- 同配置重跑会验证已有文件并续跑；损坏文件会重生成。不同配置需显式 `--overwrite`。
- manifest 只在全部所选图片生成成功后发布，失败或中断时不会留下表示本轮完成的清单。
- 对比面板依次为内容图、风格图、M、alpha、普通 AdaIN、结构保持结果。
  alpha 图使用绝对 `[0,1]` 灰度，不对每张图单独拉伸对比度。

## 指标与结论边界

样例与扫描默认计算 EdgeScore：与成员4相同，灰度后缩放到224×224，
固定 Canny 阈值100/200，计算二值边缘的 F1 重叠。任一图无边缘时记录 `null`，
均值只统计有效样本，并同时记录有效数量。

`--lpips` 可增加 LPIPS，需要另装包和模型权重。默认未计算时在 JSON 中明确记录。
这两项均为生成图分析，不进入分类器训练，也不能替代跨域分类实验。

本机使用 NN 环境和预训练权重进行了单元/接口验证。PACS 已下载并通过全量原图解码和
项目清单校验；真实七类样例与 beta 小样本扫描已生成。合成图冒烟测试仍隔离保存，
不构成真实 PACS 实验；目前还没有本方法的分类准确率结果。

正式 `data/aug_sp/images/` 已生成1349张真实增强图，并通过全量解码、标签、冻结配对、
原图/输出哈希和两份清单一致性检查。成员4脚本给出的全量 EdgeScore 为
`0.3436 ± 0.0628`（图片间标准差，n=1349），并非多 seed 分类结果。
